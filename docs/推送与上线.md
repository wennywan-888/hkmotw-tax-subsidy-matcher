## 让推送免输令牌（建议做一次）

现在每次推送都要输令牌，很烦，而且导致你把令牌到处复制——这本身就是风险。
做一次下面的操作，令牌存进 macOS 钥匙串，以后 `git push` 直接过。

打开终端，粘贴这一整段回车：

```bash
git config --global credential.helper osxkeychain
printf "protocol=https\nhost=github.com\nusername=wennywan-888\npassword=你的令牌\n\n" | git credential-osxkeychain store
```

把 `你的令牌` 换成实际的 `ghp_` 串。执行后没有任何输出就是成功了。

验证一下：

```bash
cd /Users/wennywan/WorkBuddy/2026-08-17-10-05-21/hkmo-subsidy
git push --dry-run origin main
```

不再提示输入用户名密码，就说明存好了。

> 我没法替你做这一步——写钥匙串需要你本人的用户权限。

### 想换令牌或撤销

```bash
# 删掉钥匙串里的旧凭证
printf "protocol=https\nhost=github.com\nusername=wennywan-888\n\n" | git credential-osxkeychain erase
```

然后去 https://github.com/settings/tokens 删掉旧令牌、生成新的，再重新 store。

## 关于令牌安全（重要）

**令牌等同于你 GitHub 账号的写权限。** 它能改代码、删仓库、改设置。

几条务必遵守：

- **不要贴进任何聊天窗口**（包括和我对话）。一旦贴出，那段记录里就永久留着它
- 不要提交进代码或写进文档
- 存进钥匙串就好，那是 macOS 加密保管的
- 怀疑泄露立刻去 https://github.com/settings/tokens 删掉，重新生成

如果之前已经贴过，去上面那个地址把对应令牌 **Delete** 掉，重新生成一个存进钥匙串。
删除是即时生效的，旧令牌立刻失效。

## 出问题怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| `Authentication failed` | 令牌过期或被删 | 生成新令牌，重新 store |
| `refusing to allow ... workflow` | 令牌没勾 `workflow` 权限 | 重新生成，勾上 `workflow` |
| Actions 里术语检查失败 | 引入了不规范的涉港澳台表述 | 本地跑 `python3 tools/check_terms.py` 看具体位置 |
| Actions 里数据校验失败 | JSON 结构问题或缺一手来源 | 看 Actions 日志的 `::error::` 行 |
| 部署成功但页面没变 | 浏览器缓存 | 强制刷新（`Command + Shift + R`） |
