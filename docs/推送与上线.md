## 第 1 步 · 拿一个推送令牌

GitHub 从 2021 年起不接受密码推送，必须用 **Personal Access Token**（个人访问令牌）。

打开这个地址（已经预填好权限）：

**https://github.com/settings/tokens/new?scopes=repo,workflow&description=hkmotw-matcher**

页面上：
- **Note** 已自动填 `hkmotw-matcher`
- **Expiration** 选 `90 days`（或按你习惯）
- **Select scopes** 确认勾了 `repo` 和 `workflow`
  - `repo` — 推送代码用
  - `workflow` — **必须勾**，否则推 `.github/workflows/` 里的文件会被拒
- 拉到底点 **Generate token**

生成后是一串 `ghp_` 开头的字符。**它只显示这一次，先复制下来。**

> 这串东西等同于你账号的写权限。不要贴到任何聊天窗口（包括这里），
> 不要提交进代码。用完可以随时在同一页面 Revoke。

## 第 2 步 · 推送

打开「终端」（`Command + 空格` 输入 terminal 回车），粘贴这一整段回车：

```bash
cd /Users/wennywan/WorkBuddy/2026-08-17-10-05-21/hkmo-subsidy && git push -u origin main
```

它会问两个问题：

```
Username for 'https://github.com': wennywan-888
Password for 'https://wennywan-888@github.com':
```

- Username 填 `wennywan-888`
- **Password 粘贴刚才那串 `ghp_` 令牌**（不是你的登录密码）
- 粘贴时屏幕上不会显示任何字符，这是正常的，粘完直接回车

成功的话会看到类似：

```
Enumerating objects: 60, done.
...
To https://github.com/wennywan-888/hkmotw-tax-subsidy-matcher.git
   43aa2d5..1f55c37  main -> main
```

## 第 3 步 · 开启 Pages 与 Actions 权限

推送完成后，浏览器打开仓库，按顺序做三件事。

### 3.1 开 Pages

**Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**

（不要选 "Deploy from a branch"，我们用 Actions 部署）

### 3.2 开 Actions 写权限

**Settings → Actions → General**，拉到 **Workflow permissions**：
- 选 **Read and write permissions**
- 勾上 **Allow GitHub Actions to create and approve pull requests**

**这一步不做，定时巡检开不了 PR，会直接报错。**

### 3.3 建两个标签

**Issues → Labels → New label**，建这两个（巡检工作流要用）：
- `政策巡检`
- `巡检异常`

## 可能遇到的问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `Authentication failed` | 用了登录密码而非令牌 | 回第 1 步生成令牌 |
| `refusing to allow ... workflow` | 令牌没勾 `workflow` | 重新生成，勾上 `workflow` |
| `Pages site not found` / 404 | 3.1 没做，或首次部署未生效 | 检查 Source 是否为 GitHub Actions，等 1-2 分钟 |
| `Resource not accessible by integration` | 3.2 没做 | 开 Read and write |
| `could not add label` | 3.3 没做 | 建那两个标签 |
| 巡检报大量「链接失效」 | Actions 机器在境外，抓国内政府站点受限 | 见 `docs/维护手册.md` 的降级方案 |
